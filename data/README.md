# Data

The original project used a restricted retail database supplied for educational use. Those source files are not included in this public repository.

The cleaned R script refers to three local inputs:

- `last_fixed_table.csv`
- `WeatherTable.txt`
- `gender_lookup.csv`

These were part of the original private workflow and should remain outside the public repository.

## Reproducibility

The current repository documents the SQL and R workflow but cannot reproduce the original company-specific results without the restricted source files.

A later public version can use a newly generated synthetic dataset with the same column structure and analysis flow. That would make the project runnable without redistributing the original data.
